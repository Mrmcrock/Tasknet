TASKNET ACCOUNT BADGE UPDATE

This update changes app.py so the logged-in user's name and unrated star display are injected into the existing page header beside the navigation. Your HTML pages and styles folder are not replaced.

INSTALL
1. Stop Flask in Command Prompt with Ctrl+C.
2. Back up your existing app.py.
3. Copy the included app.py into your main TaskNet folder, replacing the old app.py.
4. Keep all existing HTML files and the styles folder in their current locations.
5. Start the app again with: py app.py
6. Log in and visit Home, About, Services, Hire, Contact, and FAQs to check the badge.

NOTES
- The badge links to /profile.html.
- New accounts show five outlined stars and “Not rated yet”; no fake rating is assigned.
- The badge is injected by Flask into pages it serves. Opening the HTML files directly from File Explorer will not show it; use http://127.0.0.1:5000/.
- This is a development-stage feature. Do not use real customer accounts until the app has been reviewed and hardened for production.
