TaskNet — original account badge + age prompt

This package keeps the Flask app.py version that hides Login/Sign Up while logged in and shows the account badge at the top. The age prompt is injected automatically by Flask into served HTML pages; you do not need to link extra CSS or JavaScript files.

1. Back up your current TaskNet folder.
2. Copy these files into your TaskNet project folder, keeping your existing styles/assets folders. If prompted, replace app.py and the matching HTML pages.
3. Install Flask if needed: py -m pip install flask werkzeug
4. Start the app: py app.py
5. Open the local address printed in the terminal (usually http://127.0.0.1:5000).

The age choice lasts for the current browser session. Choosing No displays “You have to be 13 or above to use this website.” This is a client-side prompt and can be bypassed; it is not secure age verification.

Important: This project package contains the available HTML and app.py files. Keep your existing styles/assets folders because they were not included in the source ZIP available for this merge.
